# Hungarian release checklist

## Before any import

- [ ] English is the Polylang default language.
- [ ] English language code is hidden from default URLs.
- [ ] Hungarian uses `/hu/`.
- [ ] Existing English content is assigned to English without changing URLs.
- [ ] Full UpdraftPlus backup completed.
- [ ] Translation workspace validator reports zero errors.

## Content QA

- [ ] Hungarian page/post title, slug, excerpt and body reviewed.
- [ ] Gutenberg blocks, shortcodes and embeds preserved.
- [ ] Separate Hungarian WP Recipe Maker recipe created and linked.
- [ ] Ingredients, quantities, temperatures, timings and yield unchanged.
- [ ] Featured image and Hungarian alt text reviewed.
- [ ] Hungarian categories, tags and recipe collections linked.
- [ ] Internal links point to Hungarian pages only where translations exist.
- [ ] Yoast title, meta description, canonical and Open Graph checked.

## Navigation and public display

- [ ] Separate Hungarian primary and footer menus assigned.
- [ ] EN/HU selector appears only where a published counterpart exists.
- [ ] Homepage, recipe search, category filters and pagination work in Hungarian.
- [ ] Newsletter and Contact Form 7 wording reviewed in Hungarian.
- [ ] Mobile, tablet and desktop layouts checked.
- [ ] Cache cleared and incognito test completed.

## Launch

- [ ] Begin with core pages and a small approved recipe batch.
- [ ] Check Search Console indexing and hreflang after release.
- [ ] Do not publish incomplete Hungarian items merely to make the selector show.
