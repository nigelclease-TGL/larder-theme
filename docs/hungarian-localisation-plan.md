# Hungarian localisation (offline work)

This branch prepares Hungarian as an optional second language while preserving English as the unchanged default language.

Planned implementation:

- Polylang compatibility and language switcher
- Hungarian theme-interface translations
- `/hu/` URL structure for Hungarian content
- Separate Hungarian menus, pages, posts, categories and recipe translations
- No changes to existing English URLs or copy
- Translation content remains unpublished until reviewed
