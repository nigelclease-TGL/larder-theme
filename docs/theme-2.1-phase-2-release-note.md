# Theme 2.1 Phase 2 release note

Theme 2.1 Phase 2 adds an editorial connection between recipes and the Shop My Kitchen product platform.

Editors can link Kitchen Products to a recipe, insert a reusable Recommended Products block and optionally show a primary retailer button. Product pages can also surface published recipes that use the product.

The implementation remains retailer-independent, stores no live prices and does not automatically insert recommendations into existing recipes.

This is an intermediate cumulative milestone. The user-facing installation package will be produced after the approved Theme 2.1 work is complete.
